Act II · Upgrade

Spring Boot 4.1 in one pass

Normally this is done one release at a time — there are 11 steps between Spring Boot 2.6 and Spring Boot 4.1, each with its own migration work. advisor upgrade-plan apply --squash 11 squashes all of them into a single pass — no manual code changes. Then it re-reads the app to capture the new SBOM.

11 steps, one at a time → 1 pass · Boot 2.6 → 4.1
